# Ошибки при проверке API, 2026-09-16

API: `http://13.61.11.140`. Проверка выполнялась через HTTP, не браузер.

## Каталог пользователей

После успешной регистрации и входа аккаунта с ролью user:

`GET /users/` → **403**, `{"detail":"Admin role required"}`.

Фронтенд использует каталог для поиска друзей и участников чата. Для обычных пользователей нужен доступный endpoint каталога с публичными полями (например, ID и username), либо поиск по username. Открывать email и административные поля не требуется. Сейчас фронтенд предлагает отправку заявки по известному UUID; это не снимает ограничение поиска на сервере.

## Удаление профиля

`DELETE /users/me` с действующим токеном каждого из двух новых аккаунтов → **500**, `Internal Server Error`.

Администратору необходимо удалить или деактивировать оставшиеся тестовые аккаунты:

- `40ddb3ba-bbc7-46ab-8d7f-693532c0786d`
- `838a34dd-878a-4a9b-ac7f-8c90ead3a7dc`

У них имена начинаются с `qa_`, email — с `lingua-qa-`. Пароли генерировались случайно и не сохранялись. Дружеские заявки и сообщения от этих аккаунтов не отправлялись: проверка остановилась на запрете каталога. Другие аккаунты не изменялись.

## Что подтверждено

Регистрация и вход прошли у обоих аккаунтов. Поиск людей для роли user и удаление собственного профиля имеют ошибки, описанные выше. Успешный цикл отправки/принятия заявки, изменение профиля и прохождение урока этими запросами не проверены.
