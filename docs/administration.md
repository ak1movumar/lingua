# Администрирование

Раздел `/admin` доступен пользователям с ролью `admin`. Назначение первого администратора выполняется на бэкенде.

Доступно создание, редактирование и удаление языков, курсов, уроков, упражнений, достижений и заданий дня. У пользователей можно менять роль и активность. Изменение собственной роли и активности отключено. Удаление требует подтверждения. Сервер должен проверять права на каждую операцию.

Порядок наполнения каталога: язык → курс → урок → упражнения. Связанные записи выбираются из данных сервера. Варианты и правильные ответы упражнений вводятся как JSON. При редактировании пустой правильный ответ не отправляется, поскольку `ExerciseResponse` его не раскрывает. Для очистки условий достижения используется JSON `null`.

На `/achievements` администратор может выдать награду выбранному пользователю, на `/leaderboard` — обновить рейтинг. Обе операции требуют подтверждения.

## Импорт курса

Отдельная страница `/admin/import` добавляет подготовленные 12 уроков и 96 упражнений в `English for Beginners`, ID 1, язык 1, уровень A1. Материалы хранятся в `features/admin/course-import/beginner-course.ts`. Перед записью проверяется соответствие курса. Уроки добавляются после существующих, без блокировки.

Повторный запуск проверяет уже созданные записи. Незавершённая операция фиксируется локально; при неизвестном результате запроса повторная запись блокируется до сверки. Импорт не начинается при открытии страницы — его запускает администратор кнопкой.

Ограничения формата упражнений и проверки сервера описаны в [интеграции с API](backend.md).
